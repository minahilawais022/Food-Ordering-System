# Food Ordering System

A Java-based Food Ordering System that allows users to browse a menu, select food items, place and manage orders, calculate the total bill and view order details.

## Features

- View food menu
- Select food items
- Place orders
- Calculate total bill
- Manage order details
- Simple and user-friendly console interface

## Technologies Used

- Java
- Object-Oriented Programming
- Arrays
- Methods
- Loops
- Conditional Statements

## Project Purpose

This project was developed to practice core Java programming concepts and build a basic real-world food ordering application.
